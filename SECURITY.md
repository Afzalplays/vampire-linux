# Security policy

Vampire OS is experimental and is not recommended for production or systems
containing sensitive data.

Do not publish exploit details, credentials, private keys, or sensitive
reproduction data in a public issue. Use GitHub private vulnerability reporting
for this repository if enabled. Otherwise contact maintainers privately through
a verified project channel.

Include the affected commit or release, architecture, reproduction steps,
impact, and logs with secrets removed. There is currently no guaranteed
security-response SLA.
